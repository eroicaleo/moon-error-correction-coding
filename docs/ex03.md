## 3.3

Perhaps the simplest of all codes is the binary parity check code, a $(n,n−1)$code,
where $k= n−1$.
Given a message vector $𝐦 = (m_0,m_1, ...,m_{k−1})$, the codeword is
$𝐜 = (m_0,m_1, ...,m_{k−1},b)$,
where $b = \sum_{j = 0}^{k-1} m_j$ 
(arithmetic in $GF(2)$) is the parity bit. Such a code is called an even parity
code, since all codewords have even parity — an even number of 1 bits.

(a) Determine the minimum distance for this code.

It's a linear block code, so from Theorem 3.4, we have $d_{\min} = 𝑤_{\min}$.
It's not possible for a codeword to have only one $1$, so $d_{\min} = 𝑤_{\min} = 2$.

(b) How many errors can this code correct? How many errors can this code detect?

It cannot correct any error, but it can detect 1 bit error.

(c) Determine a generator matrix for this code.

Then generator matrix is an $(n-1) \times n$ matrix, the left part is an identity matrix,
while the last column is all one.

## 3.25

Let $G$ be the generator matrix of an $(n,k)$ binary code
$\mathcal{C}$ and let no column of $G$ be all
zeros. Arrange all the codewords of $\mathcal{C}$ as rows of a $2^k ×n$
array.

(a) Show that no column of the array contains only zeros.

Let $M$ be a $2^k \times k$ matrix, each row is one of the
$2^k$ messages.

And let $C = MG$, what we need to prove is that no column of
$C$ is all zeros.

We will just need to show $C[:,1]$ is not all zeros.

Since $G[:,1]$ is not all zeros, then assume $G_{i,1} = 1$.

Then consider the following message:

$$ 
m = (m_1, \cdots, m_k)
$$

where only $m_i = 1$. Then $m G[:,1]$ is not all zero.
If $m$ is the $l$th row in $C$, then $C_{l,1} = 1$.

So $C[:,1]$ is not all zeros.

For other columns we can use the same approach.

(b) Show that each column of the array consists of
$2^{k−1}$ zeros and $2^{k−1}$ ones.

**Proof**:

Consider the $j$th column of $C$, and denote it $C_{.,j}$, then
$C_{.,j} = M G_{.,j}$.

If $C_{i,j} = 0$, it means $M_{i,.} G_{.,j} = 0$, that is
the inner product of $M_{i,.} G_{.,j}$ is $0$.

Now consider $W = \text{span}(G_{.,j})$, then $\dim W = 1$. 
From Theorem 2.64, $\dim W_⟂ = k - 1$. So $|W_⟂| = 2^{k−1}$.

So $C_{.,j}$ consists of
$2^{k−1}$ zeros and $2^{k−1}$ ones.

$\square$

(c) Show that the set of all codewords with zeros in particular component positions forms a subspace of $\mathcal{C}$.
What is the dimension of this subspace?

**Proof**:

Let $V$ be the set of all codewords in $\mathcal{C}$ such that particular component positions
are $0$, let $c_0, c_1 \in V$. For $c_0 + c_1$, and $k c_0, k = 0, 1$ those particular component positions are still $0$. So $V$ is close under addition and scaler multiplication.

Now to the dimension of this subspace, assume the particular component positions are
$j_1 < j_2 < \cdots < j_p$. Then the corresponding columns in the generator matrix are
$G_{., j_1}, G_{., j_2}, \cdots, G_{., j_p}$.
Let $W = \text{span}(G_{., j_1}, G_{., j_2}, \cdots, G_{., j_p})$.

Then this subspace is in fact isomorphic to $W_{\perp}$.
So its dimension is $k - \dim W$.

$\square$

(d) Show that the minimum distance $d_{\min}$ of this code must satisfy the following inequality, known as the **Plotkin** bound:

$$ 
d_{\min} \leq 
\frac{n 2^{k-1}}{2^{k}-1}
$$

**Proof**:

From Theorem 3.4, we know $d_{\min} = 𝑤_{\min}$.
Then we just need to prove

$$ 
𝑤_{\min} (2^{k}-1) \leq n 2^{k-1}
$$

Given any non-zero codeword $c \in \mathcal{C}$, $𝑤_{\min} \leq wt(c)$,
and there are $2^{k}-1$ non-zero codewords. 
That means the total number of digit $1$ in $\mathcal{C}$ is
greater of equal to $𝑤_{\min} (2^{k}-1)$.

On the other hand, from part (b), we know the the total number of digit $1$
is exactly $n 2^{k-1}$, since each column of $C$ has $2^{k-1}$ $1$s and
$C$ has $n$ columns.

So the Plotkin bound follows.

$\square$

## 3.26

Let $Γ$ be the ensemble of all the binary systematic linear $(n,k)$ codes.

(a) Prove that a nonzero binary vector $𝐯$ is contained in exactly
$2^{(k−1)(n−k)}$ of the codes in $Γ$ or it is in none of the codes in $Γ$.

**Proof**:

We assume that for a systematic linear $(n,k)$ code, the generator matrix $G$ is like this

$$ 
G = [I | P]
$$

Basically, $I$ is an $k \times k$ matrix and $P$ is an $k \times (n-k)$ matrix.

So for a message $m$, the codeword $c = mG = (m, p)$, where $p$ is the $1 \times (n-k)$ parity bits.

Given any nonzero vector $v = (m, p)$ where $m = (m_1, \cdots, m_k), p = (p_1, \cdots, p_{n-k})$.

If $m = (0, \cdots, 0)$ and $p \neq (0, \cdots, 0)$, then $mG = 0G = 0 \neq (m, p) = v$.
So such $v$ is not contained in any code in $Γ$.

Now assume $m \neq 0$, for $p_1$, we need to find $P_{.,1}$ such that $m P_{.,1} = p_1$.

If $p_1 = 0$, then let $W = \text{span}(m)$. So $\dim W = 1$. Any vector $w$ in $W_{\perp}$ will satisfy
$⟨m,w⟩ = 0$. Since $\dim W_{\perp} = (k-1)$, we know $|W_{\perp}| = 2^{k-1}$.

On the other hand, if $p_1 = 1$, then any vector $w \not\in W_{\perp}$ will satisfy
$⟨m,w⟩ = 1$. $|GF(2)^k\backslash W_{\perp}| = 2^{k-1}$.

In either case, there are $2^{k-1}$ choices to satisfy $m P_{.,1} = p_1$.
We can apply the same argument to $P_{.,1}, \cdots, P_{.,n-k}$.

Therefore, $v$ is contained in exactly $2^{(k−1)(n−k)}$ codes.

$\square$

(b) Using the fact that the nonzero $n$-tuples of weight $d−1$ or less can be in at most

$$ 
2^{(k−1)(n−k)}
\sum_{i = 1}^{d-1}
\binom{n}{i}
$$

$(n,k)$ systematic binary linear codes, show that there exists an $(n,k)$ linear code with
minimum distance of at least $d$ if the following bound is satisfied:

$$ 
\sum_{i = 1}^{d-1}
\binom{n}{i} < 2^{n-k}
$$

**Proof**:

First note, since $P$ is an $k \times (n-k)$ matrix, we have $|\Gamma| = 2^{k(n-k)}$.

If a code $\mathcal{C}$'s minimum distance is less than $d$, then it must contain a codeword $c$ such that
$wt(c) < d$, i.e. $wt(c) = 1, \cdots, d-1$.

Since we can have at most $\sum_{i = 1}^{d-1}\binom{n}{i}$ distinct codewords with $wt(c) < d$,
and each codeword is contained in exactly $2^{(k−1)(n−k)}$ codes, then
the number of code $\mathcal{C}$ with minimum distance less that $d$ is at most

$$ 
2^{(k−1)(n−k)}
\sum_{i = 1}^{d-1}
\binom{n}{i}
<
2^{(k−1)(n−k)} \cdot 2^{n-k} = 2^{k(n-k)}
$$

So there must be at least one code in $\Gamma$, whose distance is greater or equal to $d$.

$\square$

(c) Show that there exists an $(n,k)$ binary linear code with minimum distance at least $d$ that
satisfies the following inequality:

$$ 
2^{n-k} \leq
\sum_{i = 0}^{d} \binom{n}{i}
$$

This provides a lower bound on the minimum distance attainable with an $(n,k)$ linear code
known as the **Gilbert–Varshamov** bound.

**Proof**:

Assume $d-1$ is the largest integer that satisfies $\sum_{i = 1}^{d-1} \binom{n}{i} < 2^{n-k}$,
i.e. $\sum_{i = 1}^{d-1} \binom{n}{i} < 2^{n-k} \leq \sum_{i = 1}^{d} \binom{n}{i}$ 
then use part (2), we can find a $\mathcal{C} \in \Gamma$ whose distance is $d$.

And

$$ 
\sum_{i = 0}^{d} \binom{n}{i} = 1 + \sum_{i = 1}^{d} \binom{n}{i} \geq 1 + 2^{n-k} > 2^{n-k}
$$

$\square$

## 3.29

The $[𝐮|𝐮 +𝐯]$ construction: Let $\mathcal{C}_i, i= 1,2$ be linear binary $(n,k_i)$ block codes with generator
matrix $G_i$ and minimum distance $d_i$. Define the code $\mathcal{C}$ by

$$ 
\mathcal{C} = |\mathcal{C}_1|\mathcal{C}_1 + \mathcal{C}_2| =
\{[u|u+v] : u \in \mathcal{C}_1, v \in \mathcal{C}_2\}.
$$

(a) Show that $\mathcal{C}$ has the generator

$$ 
G =
\begin{bmatrix}
    G_1 & G_1 \\
    0   & G_2 \\
\end{bmatrix}
$$

**Proof**:

$G_i$ is $k_i \times n$ matrix.
Let $m_1$ be a $1 \times k_1$ message.
Let $m_2$ be a $1 \times k_2$ message.

and $u = m_1 G_1, v = m_2 G_2$.

And

$$ 
[m_1 | m_2] G = [m_1 G_1 + 0 | m_1 G_1 + m_2 G_2] = [u | u + v]
$$

So $G$ is the generator of $\mathcal{C}$.

$\square$

(b) Show that the minimum distance of $\mathcal{C}$ is

$$ 
d_{\min} = \min (2 d_1, d_2)
$$

**Proof**:

Note that since $c = [u|u+v]$, then $wt(c) = wt(u) + wt(u+v)$.

If $v = 0$, then $wt(c) = 2 wt(u) \geq 2 d_1$.

If $v \neq 0$, then given any $u$. Let's treat $u, v$ as vector in $\mathbb{R}^n$.

So $wt(u+v) \geq wt(v) - ⟨u,v⟩$, and also $⟨u,v⟩ \leq wt(u)$.

So

$$
wt(c) = wt(u) + wt(u+v) \geq wt(u) + (wt(v) - ⟨u,v⟩) \geq wt(v) \geq d_2
$$

In either case, $wt(c) \geq \min (2 d_1, d_2)$.

Furthurmore, when $v = 0$, we can find $u$ to reach $wt(c) = 2 d_1$.
when $u = 0$, we can find $v$ to reach $wt(c) = d_2$.

So $d_{\min} = \min (2 d_1, d_2)$.

A note from AI: we can use the triangle inequality in the hamming distance to prove this

$$ 
wt(v) = d(v, 0) = d(u+v, u) \leq d(u+v, 0) + d(0, u) = wt(u+v) + wt(u) \\
\Rightarrow \\
wt(u+v) \geq wt(v) - wt(u)
$$

$\square$
