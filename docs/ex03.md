## 3.3

Perhaps the simplest of all codes is the binary parity check code, a $(n,n−1)$code,
where $k= n−1$.
Given a message vector $𝐦 = (m_0,m_1, ...,m_{k−1})$, the codeword is
$𝐜 = (m_0,m_1, ...,m_{k−1},b)$,
where $b = \sum_{j = 0}^{k-1} m_j$ 
(arithmetic in $GF(2)$) is the parity bit. Such a code is called an even parity
code, since all codewords have even parity — an even number of 1 bits.

(a) Determine the minimum distance for this code.

It's a linear block code, so from Theorem 3.4, we have $d_{\min} = 𝑤_{\min}$.
It's not possible for a codeword to have only one $1$, so $d_{\min} = 𝑤_{\min} = 2$.

(b) How many errors can this code correct? How many errors can this code detect?

It cannot correct any error, but it can detect 1 bit error.

(c) Determine a generator matrix for this code.

Then generator matrix is an $(n-1) \times n$ matrix, the left part is an identity matrix,
while the last column is all one.

The generator and parity check matrix for a binary code $\mathcal{C}$ are given by

This code is small enough that it can be used to demonstrate several concepts
from throughout the chapter.

(b) Draw a logic diagram schematic for an implementation of an encoder for the nonsystematic
generator G using ”and” and ”xor” gates.

**Solution**: I will just use verilog code instead of diagram schematic.

## 3.25

Let $G$ be the generator matrix of an $(n,k)$ binary code
$\mathcal{C}$ and let no column of $G$ be all
zeros. Arrange all the codewords of $\mathcal{C}$ as rows of a $2^k ×n$
array.

(a) Show that no column of the array contains only zeros.

Let $M$ be a $2^k \times k$ matrix, each row is one of the
$2^k$ messages.

And let $C = MG$, what we need to prove is that no column of
$C$ is all zeros.

We will just need to show $C[:,1]$ is not all zeros.

Since $G[:,1]$ is not all zeros, then assume $G_{i,1} = 1$.

Then consider the following message:

$$ 
m = (m_1, \cdots, m_k)
$$

where only $m_i = 1$. Then $m G[:,1]$ is not all zero.
If $m$ is the $l$th row in $C$, then $C_{l,1} = 1$.

So $C[:,1]$ is not all zeros.

For other columns we can use the same approach.

$\square$
